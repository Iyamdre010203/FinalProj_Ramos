# 👗 Outfit and Accessory Classifier

A deep learning-powered web app that classifies fashion items like **shirts**, **blouses**, **bags**, and more using a custom-trained model. Built with **Streamlit** for easy and interactive use.

---

## 🚀 Features

- 📷 Upload any image containing clothing or accessories
- 🧠 Classifies into categories such as:
  - Shirt
  - Blouse
  - Bag
- ⚙️ Built with TensorFlow/PyTorch 
- 🌐 Lightweight UI powered by Streamlit
